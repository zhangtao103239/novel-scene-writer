# 细纲样例：一场戏的节点写法
#
# 写法要点：
#   1. 一行 = 一个节点（模型会逐节点写出来）
#   2. 每行都要有"谁 + 做什么 + 结果"，不要写"她很难过"这种抽象情绪
#   3. 动作方式要写清（否则模型会自己造道具，比如凭空出现一把铲子）
#   4. 括号里的内容是给模型的元指令，不计入节点，也不会被当成剧情
#   5. 最后一行明确"止于哪里"，防止模型自己往前推剧情

深夜，林昭回到拆迁到一半的旧居院中。
她用手背推开虚掩的院门，门轴发出轻微的吱嘎声。
她拨开墙缝的杂草，手指探进去，取出母亲留下的铁盒。
盒内只有一把生锈的钥匙和半张照片。
她用双手把泥土一点点捧回去，把盒子埋回原处，跪下按实。
她起身，拍去膝盖上的土，转身离开，没有回头。
（止于"离开"，不得继续写她去了哪里，也不要出现任何工具）
