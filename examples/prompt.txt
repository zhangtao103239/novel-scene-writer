# 提示词四层，顺序不能乱：
#   1. 总述 —— 只覆盖这一段的范围。不写后面才确认的信息（否则穿帮）
#   2. 细纲 —— 新闻体，只写事，物件随事走不列清单
#   3. 人 —— 名字与关系（给叙述用，不等于主角知道）
#   4. 知 —— 主角此刻知道什么 / 不知道什么（堵穿帮）
#
# 脚本不改写任何内容，原样传给模型。`#` 开头的行会被丢弃。

主角喝酒睡着了，一觉醒来，发现自己穿越。

他醒在陌生床上，手和衣裳都不属于自己。
他下床走到铜镜前，看见一张不认识的脸。
平儿端着铜盆挑帘进来，唤他"二爷"，他应下，把想问的话咽回。

人：房中人唤他"二爷"，贴身丫鬟是平儿，老太太是他祖母，他父亲是贾赦。（供叙述用）
知：他不知道自己在哪，不知道自己是谁，不认识眼前这个丫鬟。
他心里只能有疑问，不能出现"贾琏""荣国府""老太太""贾赦"这些答案。
他能确认的只有一件事：这不是他原来的身体，也不是他原来的房间。
