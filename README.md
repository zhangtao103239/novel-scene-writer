# novel-scene-writer

**给一段提示词，出一段小说正文。**

用 [硅基流动](https://siliconflow.cn) 的 `Qwen/Qwen2.5-72B-Instruct`。零依赖（纯 Python 标准库），Windows / macOS / Linux 通用，主程序约 130 行。

---

## 分工

| 外部（你） | 模型 |
|---|---|
| **大局**：谁在场、发生什么、多少字 | **全部细节**：动作、环境、感官、对话、节奏、句子 |

提示词写成**新闻电讯**——一句一事，只写"人、事、物"：

```text
✅ 他醒在陌生床上，手和衣裳都不属于自己。
   他下床走到镜前，看见一张不认识的脸。
   平儿挑帘进来，唤他"二爷"，他应下，把想问的话咽回。

❌ 他睁眼，先看帐顶绣纹，闻到甜腻熏香，躺着一动不动，
   把眼睛转了一圈，抬起右手翻过来又翻过去看了两遍，
   用这只手捏了一下自己的脸颊……
```

**为什么不能把细节写进提示词**：实测那样模型只能逐条填，产出变成「一句提示换一句正文」的填表文，僵、扁、没有呼吸。把细节还给模型，它自己会补出烛台、挂帘、碗底磕桌面这些血肉。

### 三忌

| 忌 | 例子 | 为什么 |
|---|---|---|
| 忌环境清单 | 「帐顶绣纹、铜帐钩、熏香、青砖地、琵琶扣、铜镜」 | **大忌**。环境是背景不是主角，罗列环境会让正文变成静物描写 |
| 忌表演指令 | 「把手翻过来又翻过去看了两遍」 | 这是模型的活，你写了它只能照演 |
| 忌抽象情绪 | 「他非常震惊」 | 它会用「心中涌起复杂的情感」这类套话糊过去 |

## 长度靠 max_tokens，不靠提示词

```python
max_tokens = 目标字数 / 1.3     # 中文约 1.3 字/token
```

到顶就是服务端**硬截断**，脚本再把半句砍掉、回退到最后一个完整句号结尾。

实测目标 200 字：

```
[截断] max_tokens=153 到顶，回退到完整句尾 227 → 204 字
```

正好收在一个「。」上，不会留半句，也不会让它自己收尾编出后续剧情。

提示词里**一个字都不提字数**。写「约 150 字」它一律写 250 字，这个模型不听劝。

## 快速开始

```powershell
# Windows 永久写入用户环境变量（设置后需重开终端）
powershell -NoProfile -Command "[Environment]::SetEnvironmentVariable('SILICONFLOW_API_KEY','sk-xxx','User')"
```
```bash
export SILICONFLOW_API_KEY=sk-xxx          # Linux / macOS，建议写进 ~/.bashrc
git clone https://github.com/zhangtao103239/novel-scene-writer.git
cd novel-scene-writer
python scripts/write_scene.py --check
```

## 用法

```bash
python scripts/write_scene.py "他醒在陌生床上，手和衣裳都不属于自己。"
python scripts/write_scene.py "..." -w 400                    # 目标 400 字
python scripts/write_scene.py "..." --style-ref 文风.txt       # 加文风参考
python scripts/write_scene.py examples/prompt.txt -w 300      # 提示词写在文件里，传路径
python scripts/write_scene.py "..." -o 段落.txt
```

### 参数（就这些）

| 参数 | 说明 |
|---|---|
| `prompt` | 提示词（位置参数）。传文件路径时自动读取文件内容 |
| `--style-ref PATH` | 文风参考（可选） |
| `-w, --words` | 目标字数，默认 200 → 换算成 max_tokens |
| `-o, --out PATH` | 输出文件（UTF-8） |
| `--check` | 只检查环境变量 + 鉴权 |

文件里 `#` 开头的行会被当注释丢掉。

## 提示词长什么样

```text
[system]
你是一名中文小说写手。按下面的要求写小说正文。只输出正文，不要标题、不要说明。

[user]
【要求】
他醒在陌生床上，手和衣裳都不属于自己。
他下床走到镜前，看见一张不认识的脸。
设定：荣国府。房中人唤他"二爷"。贴身丫鬟叫平儿。长辈那边称"老太太"，是他的祖母。
```

没有文风预设、没有禁止项、没有字数要求。早期版本有 7 条编号规则约 400 字，模型把每条当成一格表格填，产出僵扁；删掉就活了。

## 已知局限

| 现象 | 说明 |
|---|---|
| **一定会自己往后跑** | 给一个节点它会顺带写后面几个。靠 max_tokens 截断兜住；剪掉最后半句是常规工序 |
| **否定句无效** | 写「写完就停，不要往下写任何情节」，它照样产出 2100 字并自编花园、凉亭、一群人 |
| **不给设定就会串人物** | 实测把贾琏写成「宝玉」、平儿写成「晴雯」。要把名字和关系写进提示词 |
| **会漏现代词** | 「现代生活」「速溶咖啡」「手机壳」都出现过 |
| **文风参考会带偏长度** | 范文短，产出也会变短（实测 250 字目标只出 33 字）。要长度就调 `-w` |
| **关系容易写错** | 它自己推出「老太太就是您的母亲」（贾母是贾琏的祖母） |

所以实际用法是「**外部管大局，模型写细节，人剪接尾**」。

## 排错

| 现象 | 处理 |
|---|---|
| `环境变量 SILICONFLOW_API_KEY 未设置` | 见快速开始；**设置后必须重开终端** |
| `401 / code=20012` | Key 无效，去控制台重新生成 |
| `403 Forbidden` | 该模型需实名/充值，或不在可用列表内 |
| `429 TPM limit reached` | 限流，脚本自动退避重试 3 次 |
| `503 / code=50505` | 服务过载，自动重试；持续失败换 `Qwen/Qwen2.5-32B-Instruct` |
| 中文乱码 | Windows 控制台默认 GBK，脚本已强制 UTF-8；仍乱码执行 `chcp 65001` |
